# अध्याय १: दोनों कुंडलियों का संक्षिप्त परिचय

इस अध्याय में दोनों राशि और नवांश कुंडलियों की मुख्य संरचना दी गई है।

## पी की राशि-कुंडली

मीन लग्न को प्रथम भाव मानते हुए:

| भाव | राशि और ग्रह |
|---|---|
| प्रथम | मीन: लग्न, मांदी |
| द्वितीय | मेष: शुक्र, केतु |
| तृतीय | वृषभ: सूर्य, बुध |
| चतुर्थ | मिथुन |
| पंचम | कर्क |
| षष्ठ | सिंह: मंगल |
| सप्तम | कन्या |
| अष्टम | तुला: राहु |
| नवम | वृश्चिक: गुरु वक्री |
| दशम | धनु |
| एकादश | मकर: चंद्र |
| द्वादश | कुंभ: शनि, गुलिक |

### पी की मूल संरचना

- मीन लग्न संवेदनशीलता, ग्रहणशीलता और अर्थ खोजने की प्रवृत्ति देता है।
- लग्नेश गुरु नवम भाव में होने से विश्वास, अध्ययन, गुरु, यात्रा और जीवन-दृष्टि महत्वपूर्ण हैं।
- सप्तमेश बुध सूर्य के साथ तृतीय भाव में है; संबंध में संवाद, संदेश, निर्णय और मानसिक संपर्क केंद्रीय रहते हैं।
- शुक्र केतु के साथ द्वितीय भाव में है; प्रेम, परिवार, वाणी और व्यक्तिगत मूल्यों में असामान्य या द्वंद्वात्मक अनुभव हो सकते हैं।
- आत्मकारक शनि अपनी कुंभ राशि में है; जिम्मेदारी, धैर्य और स्वतंत्र चिंतन मूल जीवन-विषय हैं।

## दिनेश की राशि-कुंडली

धनु लग्न को प्रथम भाव मानते हुए:

| भाव | राशि और ग्रह |
|---|---|
| प्रथम | धनु: लग्न, शनि |
| द्वितीय | मकर: राहु |
| तृतीय | कुंभ |
| चतुर्थ | मीन |
| पंचम | मेष |
| षष्ठ | वृषभ |
| सप्तम | मिथुन: गुरु |
| अष्टम | कर्क: केतु |
| नवम | सिंह |
| दशम | कन्या: सूर्य, चंद्र, मंगल, बुध, मांदी, गुलिक |
| एकादश | तुला: शुक्र |
| द्वादश | वृश्चिक |

### दिनेश की मूल संरचना

- धनु लग्न विचार, उद्देश्य, ज्ञान और स्पष्ट दिशा चाहता है।
- लग्नेश गुरु सप्तम भाव में है; साझेदारी और जीवनसाथी जीवन की दिशा पर बड़ा प्रभाव डालते हैं।
- सप्तमेश बुध अपनी कन्या राशि में दशम भाव में है; विवाह, काम, प्रतिष्ठा और व्यावहारिक निर्णय जुड़े हुए हैं।
- सूर्य-मंगल अत्यंत निकट हैं; इच्छाशक्ति प्रबल है, पर प्रतिक्रिया और अधिकार-बोध तीखा हो सकता है।
- आत्मकारक शुक्र अपनी तुला राशि में एकादश भाव में है; संबंध, सामंजस्य, मित्रता और सामाजिक सहयोग से विकास होता है।

## पी की नवांश कुंडली

| भाव | राशि और ग्रह |
|---|---|
| प्रथम | तुला: लग्न |
| द्वितीय | वृश्चिक |
| तृतीय | धनु: गुरु |
| चतुर्थ | मकर: चंद्र, राहु |
| पंचम | कुंभ: सूर्य |
| षष्ठ | मीन |
| सप्तम | मेष: मंगल |
| अष्टम | वृषभ |
| नवम | मिथुन: शुक्र, शनि |
| दशम | कर्क: केतु |
| एकादश | सिंह: बुध |
| द्वादश | कन्या |

पी के नवांश में लग्नेश शुक्र नवम भाव में आत्मकारक शनि के साथ है। सप्तम भाव में उसका स्वामी मंगल अपनी मेष राशि में है। संबंध की शक्ति बहुत है, लेकिन दाराकारक चंद्र का राहु के साथ होना भावनात्मक स्पष्टता को आवश्यक बनाता है।

## दिनेश की नवांश कुंडली

| भाव | राशि और ग्रह |
|---|---|
| प्रथम | मिथुन: लग्न, चंद्र, शुक्र |
| द्वितीय | कर्क |
| तृतीय | सिंह: शनि |
| चतुर्थ | कन्या: राहु |
| पंचम | तुला |
| षष्ठ | वृश्चिक |
| सप्तम | धनु |
| अष्टम | मकर: बुध |
| नवम | कुंभ: गुरु |
| दशम | मीन: केतु |
| एकादश | मेष: मंगल |
| द्वादश | वृषभ: सूर्य |

दिनेश के नवांश में आत्मकारक शुक्र लग्न में चंद्र के साथ है। सप्तमेश गुरु नवम भाव में है। दाराकारक और नवांश लग्नेश बुध अष्टम भाव में होने से विश्वास, संयुक्त धन और गहरे संवाद विवाह के मुख्य विषय बनते हैं।

## प्रारंभिक तुलना

- दोनों राशि लग्न गुरु की राशियाँ हैं।
- दोनों नवांश लग्न वायु तत्व की राशियाँ हैं और पंचम-नवम संबंध बनाते हैं।
- दोनों का सप्तमेश बुध है।
- दोनों के नवांश में राहु चतुर्थ और केतु दशम भाव में है।
- दोनों का मंगल मेष नवांश में अपनी राशि में है।

इन समानताओं से साझा जीवन-दृष्टि, मानसिक संपर्क और सक्रिय आकर्षण मिलता है। मंगल और राहु की पुनरावृत्ति संबंध को शांत से अधिक तीव्र बनाती है।
